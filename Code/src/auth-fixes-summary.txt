Phase 4: Frontend Auth Infrastructure
---------------------------------------

15. src/contexts/AuthContext.tsx — NEW FILE
    Central auth state provider wrapping the entire app
    Provides: user, token, isAuthenticated, login(), logout()
    On mount: reads from localStorage, parses user JSON
    login(): writes to localStorage + updates React state
    logout(): clears localStorage + React state
    Why: Before, components read/wrote localStorage inconsistently.
         Now there's a single source of truth.

16. src/utils/api.ts — NEW FILE
    Centralized HTTP client wrapping fetch()
    Auto-injects Authorization: Bearer <token> on every request
    On 401:
      1. Tries to refresh using stored refresh_token
      2. If refresh succeeds: stores new tokens, retries request
      3. If refresh fails: clears auth, redirects to /login
    Why: Before, no API request ever sent the token.
         Also adds automatic session recovery.
